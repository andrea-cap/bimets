# Your first model

[Back to the tutorial index](README.md)

This tutorial defines a minimal accounting model, binds quarterly data, and
runs a deterministic simulation. No coefficient estimation is required.

## Define the model

```python
from bimets import load_model

model = load_model(
    model_text="""MODEL
IDENTITY> income
EQ> income = consumption + investment
END""",
    name="income-identity",
)

model.endogenous  # ('income',)
model.exogenous   # ('consumption', 'investment')
```

`IDENTITY>` declares an accounting or definitional relationship. A behavioral
equation instead contains coefficients that can be estimated from data.

## Bind model data

```python
from bimets import BimetsDataset, timeseries

data = BimetsDataset({
    "income": timeseries([0.0, 0.0, 0.0], start=(2024, 1), freq="Q"),
    "consumption": timeseries(
        [80.0, 82.0, 84.0], start=(2024, 1), freq="Q"
    ),
    "investment": timeseries(
        [20.0, 21.0, 19.0], start=(2024, 1), freq="Q"
    ),
})

bound = model.bind(data)
```

Binding validates that all required variables exist and use a compatible
frequency. It returns a new `BoundModel`; neither the model nor the dataset is
mutated.

## Simulate

```python
result = bound.simulate(
    coefficients={},
    time_range=(2024, 1, 2024, 3),
)

result["income"].values
# array([100., 103., 103.])

result.summary()
#              income
# year period
# 2024 1        100.0
#      2        103.0
#      3        103.0
```

The same operation is available as `simulate(model, data, ...)` and
`model.simulate(data, ...)`. Continue with the [MDL guide](05.mdl.md), then the
[estimation](06.estimation.md) and [deterministic simulation](07.simulation.md)
guides for behavioral equations and dynamic models.
