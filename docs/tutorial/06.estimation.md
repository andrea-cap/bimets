# Model estimation

[Back to the tutorial index](README.md)

`BimetsModel.bind()` associates a parsed model with a `BimetsDataset`, checks
that every model variable is present, and requires a common frequency. The
result is an immutable `BoundModel`. Estimation can then be run either as a
method or with the equivalent `estimate()` function:

```python
bound = model.bind(data)

results = bound.estimate()
same_results = estimate(model, data)
```

The following complete example estimates the consumption equation from the
original Klein Model 1 data distributed with BIMETS:

```python
from bimets import BimetsDataset, BimetsModel, estimate, timeseries

consumption_model = BimetsModel.from_text(
    """MODEL
BEHAVIORAL> cn
TSRANGE 1921 1 1941 1
EQ> cn = a1 + a2*p + a3*TSLAG(p,1) + a4*(w1+w2)
COEFF> a1 a2 a3 a4
END""",
    name="klein-consumption",
)

klein_data = BimetsDataset({
    "cn": timeseries([
        39.8, 41.9, 45, 49.2, 50.6, 52.6, 55.1, 56.2, 57.3, 57.8, 55,
        50.9, 45.6, 46.5, 48.7, 51.3, 57.7, 58.7, 57.5, 61.6, 65, 69.7,
    ], start=(1920, 1)),
    "p": timeseries([
        12.7, 12.4, 16.9, 18.4, 19.4, 20.1, 19.6, 19.8, 21.1, 21.7,
        15.6, 11.4, 7, 11.2, 12.3, 14, 17.6, 17.3, 15.3, 19, 21.1, 23.5,
    ], start=(1920, 1)),
    "w1": timeseries([
        28.8, 25.5, 29.3, 34.1, 33.9, 35.4, 37.4, 37.9, 39.2, 41.3,
        37.9, 34.5, 29, 28.5, 30.6, 33.2, 36.8, 41, 38.2, 41.6, 45, 53.3,
    ], start=(1920, 1)),
    "w2": timeseries([
        2.2, 2.7, 2.9, 2.9, 3.1, 3.2, 3.3, 3.6, 3.7, 4, 4.2, 4.8,
        5.3, 5.6, 6, 6.1, 7.4, 6.7, 7.7, 7.8, 8, 8.5,
    ], start=(1920, 1)),
})

bound = consumption_model.bind(klein_data)
consumption = bound.estimate()["cn"]
same_consumption = estimate(consumption_model, klein_data)["cn"]
dict(consumption.coefficients)
# {
#     'a1': 16.2366003,
#     'a2': 0.1929344,
#     'a3': 0.0898849,
#     'a4': 0.7962187,
# }

consumption.observations       # 21
consumption.r_squared          # 0.9810082
consumption.standard_error     # 1.02554
consumption.residuals          # BimetsSeries covering 1921--1941
consumption.covariance         # read-only NumPy coefficient covariance matrix
```

The estimator supports ordinary least squares and instrumental variables:

```python
ols = bound.estimate(method="OLS")

iv = bound.estimate(
    method="IV",
    instruments=("1", "p", "TSLAG(p)", "TSLAG(w1)+w2"),
)
```

For IV estimation, `instruments=` overrides any `IV>` declarations in the
selected behavioral equations. If no override is supplied, the declarations
are used. Instrument expressions are parsed and evaluated by the same safe MDL
expression engine as equation regressors.

The following estimation features are applied directly from MDL:

- `RESTRICT>` deterministic linear coefficient restrictions;
- `PDL>` Almon polynomial distributed-lag expansion, including the `N` and `F`
  endpoint restrictions and references such as `LAG(coefficient, 2)`;
- `ERROR> AUTO(n)` error autocorrelation through the iterative
  Cochrane--Orcutt procedure used by BIMETS.

Results provide expanded coefficients, covariance and regressor matrices,
standard errors, t-statistics and p-values, corrected and uncorrected
residuals, autoregressive coefficients and diagnostics, restriction F tests,
R-squared diagnostics, Durbin--Watson, log-likelihood, the regression F test,
AIC, and BIC. Stored mappings and NumPy arrays are read-only.

Without a `TSRANGE`, estimation uses the common temporal intersection of the
dependent variable and all non-scalar regressors. With a declared `TSRANGE`,
that exact inclusive sample is required. Missing or non-finite observations
inside it are rejected rather than silently dropped. `equations=` can select
one name or a sequence of behavioral equation names. Autoregressive errors and
PDLs may require additional observations before the estimation range.

A call-level range follows the same precedence rule as BIMETS R: the local MDL
range wins unless the override is forced explicitly.

```python
result = consumption_model.estimate(
    klein_data,
    time_range=(1925, 1, 1935, 1),
    force_time_range=True,
    tol=1e-12,
)
```

## Structural stability and summaries

Set `chow_test=True` to compare the base estimation with an extended sample.
`chow_end` selects its final period; if omitted, bimets uses the latest period
shared by the equation inputs:

```python
result = consumption_model.estimate(
    klein_data,
    equations="cn",
    time_range=(1925, 1, 1935, 1),
    force_time_range=True,
    chow_test=True,
    chow_end=(1941, 1),
)

consumption_stability = result["cn"]
consumption_stability.summary()  # coefficient table as a pandas DataFrame
result.summary()            # all equations with a two-level index

chow = consumption_stability.chow_test
chow.f_statistic
chow.f_probability
chow.summary()              # actual, prediction, error, SE, and t statistic
```

The Chow result follows the BIMETS covariance-analysis formula and supplies
out-of-sample actual values, predictions, forecast errors, standard errors,
and t-statistics as `BimetsSeries` objects.

See the [estimation API reference](../reference/estimation.md) for complete
signatures and result attributes. Numerically intentional differences from
BIMETS R, including restriction solving and default tolerances, are listed in
[Key differences from BIMETS R](../explanation/migration-from-r.md).
