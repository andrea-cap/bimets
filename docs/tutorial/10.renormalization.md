# Endogenous targeting and renormalization

[Back to the tutorial index](README.md)

In BIMETS terminology, renormalization is an endogenous-targeting operation;
it does not rewrite an MDL equation algebraically. `renormalize()` determines
the paths of an equal number of policy instruments that make selected
endogenous variables approach desired target paths. Its exact BIMETS R alias is
`RENORM()`. The equivalent methods are `model.renormalize()` and
`bound_model.renormalize()`.

At every iteration the procedure:

1. computes the square dynamic or static multiplier matrix of targets with
   respect to instruments;
2. solves that linear system for an instrument correction;
3. simulates the corrected model and checks the Euclidean error norm of every
   target.

```python
from bimets import BimetsModel, renormalize, timeseries

targeting_model = BimetsModel.from_text(
    """MODEL
IDENTITY> y
EQ> y = 2 * x
END""",
    name="targeting-example",
)
targeting_data = {
    "y": timeseries([0], start=(2000, 1)),
    "x": timeseries([1], start=(2000, 1)),
}

targeting_result = renormalize(
    targeting_model,
    targeting_data,
    coefficients={},
    time_range=(2000, 1, 2000, 1),
    targets={"y": timeseries([10], start=(2000, 1))},
    instruments="x",
    simulation_type="STATIC",
)
targeting_result.converged
# True
targeting_result.instruments["x"].values.round(6).tolist()
# [5.0]
targeting_result.achieved_targets["y"].values.round(6).tolist()
# [10.0]

# Equivalent method forms
same_targeting = targeting_model.renormalize(
    targeting_data,
    coefficients={},
    time_range=(2000, 1, 2000, 1),
    targets={"y": timeseries([10], start=(2000, 1))},
    instruments="x",
    simulation_type="STATIC",
)
bound_targeting = targeting_model.bind(targeting_data).renormalize(
    coefficients={},
    time_range=(2000, 1, 2000, 1),
    targets={"y": timeseries([10], start=(2000, 1))},
    instruments="x",
    simulation_type="STATIC",
)
```

An exogenous instrument is replaced in `result.data`. If an endogenous
variable is selected as an instrument, its equation add-factor is adjusted and
returned in `result.constant_adjustments`; this supports automatic baseline
fine-tuning and forecast add-factor calculation, as in BIMETS R. Neither the
input model nor the original dataset is mutated.

The result also exposes `desired_targets`, `achieved_targets` (with `targets`
as a BIMETS-compatible property), the final deterministic `simulation`, the
last `multiplier_matrix`, iteration diagnostics, and `summary()`. If the
iteration limit is reached, these diagnostics remain available with
`converged=False` and `unconverged_targets` identifying the outstanding
objectives; a `RuntimeWarning` is emitted as in BIMETS R.

The Klein example from the original BIMETS documentation targets consumption
at `66, 78` and GNP at `77, 98` in 1940--1941 using government wages `w2` and
government expenditure `g`. With `convergence=1e-8`, the Python port reproduces
the BIMETS R 4.1.2 instrument paths:

```text
w2:  7.404308,  9.327926
g:  16.102687, 22.651635
```

The targeting convergence criterion is controlled independently by
`renormalization_convergence`; observations with a zero desired value use an
absolute error, matching BIMETS. `matrix_tolerance` controls detection of a
singular or numerically dependent instrument-target system. Backward-looking
and forward-looking models are both supported, using the same solver settings
as deterministic simulation and multiplier matrices.

`FULLNEWTON` can be selected for nonlinear targeting runs. Its independent
multiplier shocks can use multiple `workers` processes; the default is one.
Shared Gauss-Seidel and ordinary-Newton paths require `workers=1`. When
`backfill` is positive, the final simulation includes historical observations,
while desired and achieved target series remain restricted to the targeting
range.
`jacobian_drop` is forwarded to every multiplier and targeting simulation.

See the [renormalization API](../reference/renormalization.md) for complete
signatures, diagnostics, and failure types.
