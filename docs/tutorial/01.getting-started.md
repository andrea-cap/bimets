# Getting started

[Back to the tutorial index](README.md)

This tutorial introduces the core objects through a small quarterly GDP
dataset. It assumes basic Python knowledge but no previous experience with
BIMETS R.

## Create a time series

`timeseries()` is the standard user-facing constructor. Values are stored in a
`BimetsSeries`, together with an explicit start period and frequency:

```python
from bimets import timeseries

gdp = timeseries(
    [100.0, 102.0, 105.0, 108.0],
    start=(2023, 1),
    freq="Q",
)

gdp.start       # YearPeriod(year=2023, period=1)
gdp.end         # YearPeriod(year=2023, period=4)
gdp.freq        # Frequency.QUARTERLY
gdp.values      # array([100., 102., 105., 108.])
```

The period component is one-based: quarterly periods range from 1 to 4 and
monthly periods from 1 to 12. Positional Python indexing remains zero-based.

```python
gdp[0]                    # 100.0
gdp.at_period(2023, 3)    # 105.0
gdp[[2023, 3]]            # 105.0, BIMETS R-style read access
```

## Calculate growth and lags

Operations are available as functions and, where appropriate, as methods:

```python
from bimets import tsdeltap, tslag

growth = tsdeltap(gdp)
previous_gdp = tslag(gdp)

# Equivalent method forms
same_growth = gdp.delta_percent()
same_previous_gdp = gdp.lag()

growth.values
# array([2.        , 2.94117647, 2.85714286])
```

The growth series starts in 2023 Q2 because its first value needs the
preceding GDP observation. BIMETS transformations preserve only periods for
which the requested lag is available rather than inserting a leading missing
value.

## Work with named data

`BimetsDataset` groups related series while preserving their calendars:

```python
from bimets import BimetsDataset

data = BimetsDataset({"gdp": gdp, "gdp_growth": growth})
frame = data.to_frame()
restored = BimetsDataset.from_frame(frame)
```

Updates are immutable. Here a scenario replaces the last two GDP observations
without modifying `data`:

```python
scenario = data.assign_range(
    {"gdp": [110.0, 112.0]},
    start=(2023, 3),
    end=(2023, 4),
)

data["gdp"].values      # array([100., 102., 105., 108.])
scenario["gdp"].values  # array([100., 102., 110., 112.])
```
