# Tutorials

[Back to the documentation index](../README.md)

These tutorials range from time-series basics to complete econometric
workflows. New users should follow them in the order below; experienced BIMETS
users can jump directly to the topic they need.

1. [Getting started](01.getting-started.md) introduces the core objects with a
   small quarterly dataset.
2. [Time series](02.timeseries.md) covers construction, access and indexing,
   calendars, transformations, conversion, datasets, pandas, and CSV.
3. [Manipulating time series](03.manipulating-timeseries.md) applies the most
   common operations in one continuous example.
4. [Your first model](04.first-model.md) defines and simulates a minimal MDL
   model.
5. [Model Description Language](05.mdl.md) documents the supported model
   syntax and intentional exclusions.
6. [Model estimation](06.estimation.md) covers OLS, IV, restrictions, PDL,
   autoregressive errors, and Chow tests.
7. [Deterministic simulation](07.simulation.md) introduces backward- and
   forward-looking solution algorithms.
8. [Stochastic simulation](08.stochastic.md) adds Monte Carlo disturbances and
   result summaries.
9. [Multiplier matrices](09.multipliers.md) covers static impact and dynamic
   interim multipliers.
10. [Renormalization](10.renormalization.md) performs endogenous targeting with
    policy instruments.
11. [Optimization](11.optimization.md) presents Monte Carlo optimal control.
