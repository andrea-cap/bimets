# Manipulating time series

[Back to the tutorial index](README.md)

This tutorial develops a small quarterly macroeconomic dataset and shows the
operations most often needed before estimation or simulation.

## Prepare related series

```python
import numpy as np

from bimets import BimetsDataset, timeseries

gdp = timeseries(
    [100.0, 102.0, 105.0, 108.0, 111.0, 115.0],
    start=(2022, 1),
    freq="Q",
)
consumption = timeseries(
    [60.0, 61.0, np.nan, 64.0, 66.0, 68.0],
    start=(2022, 1),
    freq="Q",
)
data = BimetsDataset({"gdp": gdp, "consumption": consumption})
```

Series in a model dataset normally share a frequency. They may have different
ranges; operations such as merge and join make the alignment choice explicit.

## Lag, lead, and differences

```python
gdp_lag = gdp.lag(periods=1)
gdp_lead = gdp.lead(periods=1)
gdp_change = gdp.delta()
gdp_growth = gdp.delta_percent()
log_growth = gdp.delta_log()
```

Lagging and leading leave the observations unchanged but shift their calendar
range forward or backward. Differencing shortens the range because it retains
only periods for which the requested lagged value is available; it does not
insert missing boundary observations.

## Select and extend a range

```python
sample = gdp.project(start=(2022, 3), end=(2023, 1))
projected = sample.project(start=(2022, 1), end=(2023, 2), extend=True)
extended = gdp.extend(up_to=(2023, 4), mode="constant")

with_missing_edges = timeseries(
    [np.nan, 1.0, 2.0, np.nan], start=(2022, 1), freq="Q"
)
trimmed = with_missing_edges.trim()
```

Use `project()` to select or place a series on a requested range, `extend()` to
extrapolate before or after its existing range, and `trim()` to remove missing
or selected values from its boundaries. These operations return new series.

## Moving and cumulative calculations

```python
moving_average = gdp.moving_average(window=4)
moving_total = consumption.moving_sum(window=4, skip_missing=True)
cumulative_change = gdp_change.cumulative_sum(
    skip_missing=True,
    start=(2022, 2),
    end=(2023, 4),
)
```

`start` and `end` restrict the calculation before accumulation, matching R's
`TSRANGE`; either bound can be omitted to use the corresponding source edge.
`skip_missing` controls whether missing observations are ignored. Choose it
explicitly when missing values have economic meaning; silently replacing them
with zero can change a flow aggregate.

## Rebase and combine series

```python
gdp_index = gdp.index_number(base_year=2022)

from bimets import tsjoin, tsmerge

historical = gdp.project((2022, 1), (2022, 4))
forecast = timeseries([111.0, 115.0], start=(2023, 1), freq="Q")
combined = tsjoin(historical, forecast)

alternative_estimate = timeseries(
    [104.5, 108.5, 111.5], start=(2022, 3), freq="Q"
)
reconciled = tsmerge(gdp, alternative_estimate, method="average")
```

`tsjoin()` takes observations before the join point from the first series and
the following observations from the second. `tsmerge()` covers the union of
the ranges and combines overlaps with the selected rule. Both preserve the
calendar and return a `BimetsSeries`.

## Convert frequency

```python
annual_gdp = gdp.to_frequency("Y", method="average")
annual_consumption = consumption.to_frequency("Y", method="nsum")
```

The aggregation method depends on the variable: averages are common for rates
or indexes, sums for flows, and first or last observations for stocks. The
methods prefixed with `n`, such as `nsum` and `naverage`, ignore missing values.
The complete [time-series guide](02.timeseries.md) documents indexing,
disaggregation, daily calendars, CSV exchange, masks, and all functional
equivalents.

## Apply a scenario to a dataset

```python
scenario = data.assign_range(
    {"gdp": 120.0, "consumption": [70.0, 72.0]},
    start=(2023, 1),
    end=(2023, 2),
)
```

Scalars are broadcast across the inclusive range. Sequences must contain one
value for every selected period. The original `data` remains unchanged, which
makes baseline and alternative scenarios safe to compare.
